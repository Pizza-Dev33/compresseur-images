# 🚀 Compresseur d'Images Léger et Local

Un outil de bureau **gratuit, open-source et 100 % confidentiel** pour compresser et convertir vos images par lots sans détruire leur qualité visuelle. Conçu en Python avec `Pillow` et `Tkinter`.

## ✨ Fonctionnalités
- 📂 **Traitement par lots :** Compressez tout un dossier d'images en un seul clic.
- 🔒 **Confidentialité totale :** Tout fonctionne en local sur votre machine, aucune image n'est envoyée sur internet.
- ⚡ **Formats modernes :** Supporte le JPEG, PNG, BMP et permet la conversion automatique vers le format **WebP** (idéal pour le web).
- 📐 **Redimensionnement intelligent :** Option pour réduire la largeur/hauteur des images trop lourdes (ex: photos de smartphone).

## 🛠️ Installation et Lancement

1. **Cloner le projet :**
   ```bash
   git clone https://github.com
   cd images-de-compresseur
   ```

2. **Installer les dépendances :**
   ```bash
   pip install -r requirements.txt
   ```

3. **Lancer l'application :**
   ```bash
   python main.py
   ```
